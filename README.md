# Inventory Management System (Python + MySQL)

A simple beginner-friendly Inventory Management System built using Python and MySQL.

This project demonstrates how to connect Python with a MySQL database and perform basic CRUD operations.

---

## 🚀 Features

- Add new products
- View all products
- Store data in MySQL database
- Simple command-line interface (CLI)
- Continuous menu system

---

## 🛠️ Technologies Used

- Python
- MySQL
- mysql-connector-python
